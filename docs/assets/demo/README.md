# 产品演示资产

- `demo-1080p.mp4`：60.6 秒 · 1920×1080 · 30fps · H.264 + AAC · 中文男声旁白。
- `screenshots/`：14 个页面中的代表性截图，Playwright 以 1920×1080 捕获。
- 截图与视频中的业务数字来自项目的**演示数据**，不代表实时生产数据。

## 旁白文稿

1. 招投标采购 Agent，智能问答与决策平台。四路数据源，让标讯、法规与价格洞察一屏掌握。
2. 工作台汇总标讯规模、供应商覆盖与最新动态，关键指标一屏掌握。
3. 智能问答融合 RAG 检索、知识图谱与结构化数据库，回答附带可追溯来源并自动核对。
4. 知识图谱按实体展开关系网络，采购人、供应商与标的物的连接一目了然。
5. 集采分析以中位数优先，呈现金额分布、供应商排行与市场集中度。
6. 标讯提取支持文本与截图，一键抽取十七个结构化字段，可直接写入业务库。
7. 五条评测线与多 Agent 灰度指标，让检索质量与延迟持续可观测。
8. FastAPI、React、Qdrant、Neo4j、PostgreSQL，MIT 开源。招采智脑，让决策更有依据。

## 生成方式

- 截图：Vite dev server + Playwright，`/api/**` 由脚本按真实响应契约返回演示夹具；全部页面在 1920×1080 下捕获。
- 旁白：`edge-tts`，音色 `zh-CN-YunxiNeural`（中文男声），每段单独生成后按场景时长拼接。
- 画面：Pillow 生成 1920×1080 幻灯片（深色科技风 + 产品截图窗口），ffmpeg `zoompan` 缓慢推近 + `xfade` 转场。
- 编码：`libx264` CRF 22，`yuv420p`，AAC 160k，`+faststart`；音频响度归一化到 -16 LUFS。
