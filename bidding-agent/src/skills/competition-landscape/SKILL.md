按以下步骤分析某个标的物 / 地区 / 采购人维度的竞争格局：

1. **先拆解分析维度**，明确问的是哪一个（三者结论不同，不要混答）：
   - **按标的物**：这个品类有哪些供应商在做；
   - **按地区**：某地区的供应商构成；
   - **按采购人**：某采购单位常与哪些供应商合作。

2. **图谱查关系，业务库查数值**，两者都要用：
   - 知识图谱（search_knowledge_graph）查：标的物 ↔ 供应商 ↔ 采购单位
     的关联关系与交易频次，以及**企业主体别名**（同一公司的不同写法）；
   - 业务数据库（query_database）查：中标金额、中标次数、时间分布。
   图谱给"谁和谁有关系"，业务库给"多大金额、几次"——只用其中一个会答不完整。

3. **企业名称要先做别名归一**。企业名称常有简称、全称、字数差异
   （如「华中电力建设公司」与「华中电力建设有限公司」）。
   查不到某个名称时，**先换几种写法再下结论**，不要一次查不到就说"无记录"。
   若各写法都查不到，如实说明"未检索到该企业"，并说明已尝试的写法。

4. **金额必须标明单位与来源**。业务库返回的金额单位是**元**，
   呈现时换算成万元/亿元并保留合理精度（如 14382650.79 元 → 1438.27 万元）。
   换算要算对——写错数量级会让整个分析失去意义。

5. **给出集中度判断，而不只是罗列**：
   - 头部供应商拿走多少份额（能算就算，算不了就说"样本不足"）；
   - 是少数几家垄断还是长尾分散；
   - 本地企业与外地/央企国企背景企业的构成。

6. **样本边界要说明**：数据来自本地业务库，有明确的时间与地区覆盖范围。
   若命中记录很少（如 1~3 条），必须说明「样本量小，仅供参考」——
   **不要**用几条记录得出"市场格局"这类结论。

7. **输出结构**：主要参与者（表格：供应商 / 代表项目 / 中标金额）
   → 集中度判断 → 数据边界与样本量说明。
   每一行数据都要能在工具结果里找到出处，不要补记忆中"听说过"的公司名。
