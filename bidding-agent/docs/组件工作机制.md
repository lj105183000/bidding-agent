## 4. 混合检索流水线（src/rag/）

查询先按词表分类（keyword / concept / mixed），映射不同 RRF k 值；Qdrant `Prefetch + RrfQuery` 原生融合 dense 与 sparse 双路结果，召回 30 条后经 CrossEncoder 精排取 top-k，结果带 128 条 LRU 缓存。

```mermaid
flowchart TB
  subgraph RAG["📚 混合检索流水线（src/rag/pipeline.py + vector_store.py）"]
    direction TB
    R0(["用户问题"]) --> R1{"_classify_question<br/>关键词 ≥2 → keyword<br/>概念词 ≥2 且无关键词 → concept<br/>其余 → mixed"}
    R1 -->|"keyword"| R2["RRF k=30<br/>偏重 Sparse 关键词精确匹配"]
    R1 -->|"concept"| R3["RRF k=90<br/>偏重 Dense 语义泛化"]
    R1 -->|"mixed"| R4["RRF k=60<br/>均衡融合"]
    R2 & R3 & R4 --> R5["双路编码<br/>dense: BGE 前缀「为这个句子生成<br/>表示以用于检索相关文章：」<br/>sparse: jieba BM25 权重"]
    R5 --> R6["query_points<br/>Prefetch(dense, limit=30)<br/>+ Prefetch(sparse, limit=30)<br/>+ RrfQuery 融合"]
    R6 --> R7{"召回结果多于 top_k？"}
    R7 -->|"是"| R8["reranker.rerank<br/>CrossEncoder 对 (query, answer) 重打分<br/>降序取 top_k"]
    R7 -->|"否"| R9["直接返回"]
    R8 --> R10["_cached_search<br/>LRU 缓存 128 条<br/>(question, top_k) 键"]
    R9 --> R10
    R10 --> R11(("docs 列表<br/>question/answer/score"))
  end

  classDef cRAG fill:#fce7f3,stroke:#db2777,stroke-width:2px,color:#0b0b0b;
  classDef cOK fill:#cfeccf,stroke:#0ca30c,stroke-width:2px,color:#0b0b0b;
  class R0,R1,R2,R3,R4,R5,R6,R7,R8,R9,R10 cRAG;
  class R11 cOK;
  style RAG fill:#fce7f3,stroke:#db2777,stroke-width:1.5px;
```

```mermaid
    D1 -->|"疑似格式"| D3["_normalize_tool_content<br/>工具回合 content 清空<br/>(防止格式文本混入最终回答)"]
```
