# 可增加的 Agent 功能

当前系统已具备 3 个工具 + Vision 图片解析。以下是可扩展的 Agent 功能，按优先级排列。

---

## 一、高优先级（直接提升用户价值）

### 1. 投标文件智能解析（Document Parser）
- **功能**：上传 PDF/Word 招投标文件，Agent 自动提取关键信息（项目名称、预算、资质要求、评分标准、截止日期等）
- **技术方案**：`PyMuPDF` + `python-docx` 提取文本 → LLM 结构化抽取 → 存入 PostgreSQL
- **用户价值**：将数十页招标文件压缩为一页摘要，大幅提升阅读效率

### 2. 联网搜索（Web Search）完成
- **功能**：当本地知识库无答案时，Agent 自动搜索最新招投标公告、法规更新
- **技术方案**：智谱AI `web_search` 工具（zai SDK 已内置）或 SearXNG 自建搜索
- **用户价值**：突破本地数据时效性限制，获取最新政策

### 3. 流式输出（Streaming）完成
- **功能**：LLM 回答逐字流式返回，用户无需等待完整生成
- **技术方案**：FastAPI `StreamingResponse` + `zai` SDK `stream=True` + 前端 `EventSource`
- **用户价值**：体验显著提升，长回答场景感知延迟降低 80%

### 4. 对话历史持久化（完成）
- **功能**：用户对话历史存入数据库，支持跨会话恢复、搜索历史对话
- **技术方案**：PostgreSQL 存储 `{session_id, user, messages, created_at}`，侧边栏加载历史
- **用户价值**：工作不丢失，可回溯之前的分析结果

---

## 二、中优先级（行业专用能力）

### 5. 资格审查辅助（Qualification Checker）
- **功能**：上传招标文件 + 企业资质 → Agent 自动比对资质要求是否满足
- **技术方案**：Document Parser 提取资质要求 → 与用户提供的资质清单做匹配 → 输出缺口报告
- **示例**："我公司有建筑一级资质，能投这个标吗？"

### 6. 价格分析与对标（Price Benchmarking）
- **功能**：输入标的物 → Agent 分析历史中标价格分布 → 给出建议报价区间
- **技术方案**：PostgreSQL `AVG/PERCENTILE` + 价格趋势图 + LLM 解读
- **示例**："空调采购的中标均价是多少？合理报价区间？"

### 7. 投标书辅助生成（Bid Drafting）
- **功能**：根据招标要求，Agent 生成投标文件草稿（技术方案、商务报价等）
- **技术方案**：RAG 检索相似案例 → LLM 基于模板生成 → 用户编辑确认
- **示例**："帮我写一份针对XX项目空调采购的技术方案"

### 8. 竞争对手分析（Competitor Intelligence）
- **功能**：输入标的物 → Agent 分析哪些供应商经常中标、中标金额分布
- **技术方案**：Neo4j 图查询 `(:Supplier)-[:SUPPLIED_BY]->(:SubjectMatter)` + 聚合统计
- **示例**："空调采购的主要竞争对手有哪些？他们平均中标价是多少？"

## 三、低优先级（增强体验与自动化）

### 9. 截止日期监控（Deadline Monitor）
- **功能**：Agent 自动扫描临近截止日期的项目，主动推送提醒
- **技术方案**：PostgreSQL 定时任务 + 前端通知/邮件推送
- **示例**："XX项目还有3天截止，是否准备投标？"

### 10. 合规性检查（Compliance Checker）
- **功能**：检查招标文件是否存在排他性条款、不合理条件等合规风险
- **技术方案**：LLM 逐条分析 → 标注风险等级 → 给出法规依据
- **示例**："这个项目要求'必须在本地有分支机构'是否合规？"

### 11. 多轮深度分析（Multi-turn Deep Dive）
- **功能**：Agent 记住上下文，支持追问、对比、深入分析
- **技术方案**：改进 Agent loop → 支持连续多轮 tool call → 自动追问
- **示例**："对比A项目和B项目的供应商要求，哪个更严格？"

### 12. 报告导出（Report Export）
- **功能**：将分析结果导出为 PDF/Word 报告
- **技术方案**：`python-docx` / `weasyprint` 生成文档
- **示例**："将空调采购市场分析导出为报告"

### 13. 数据看板（Dashboard）
- **功能**：独立页面展示关键指标（中标金额趋势、活跃采购人 TOP10、标的物热力图）
- **技术方案**：Recharts/ECharts 图表 + PostgreSQL 聚合查询 + 自动刷新
- **示例**：首页仪表盘展示实时采购数据

### 14. 多 Agent 协作（Multi-Agent）
- **功能**：不同 Agent 分工（检索 Agent、分析 Agent、写作 Agent），协作完成复杂任务
- **技术方案**：LangGraph / CrewAI 编排 → 定义 Agent 角色和工作流
- **示例**：一个 Agent 查法规、一个 Agent 查案例、一个 Agent 写方案，最终合并

### 15. 企业关系图谱可视化
- **功能**：Neo4j 查询结果以可视化关系图展示（而非纯文本）
- **技术方案**：前端 `d3.js` / `vis-network` 渲染力导向图
- **示例**：查询"空调" → 展示标的物-采购人-供应商的关系网络图
